# _废弃备份

这里放**已从面板下线的脚本**，保留原始代码以备回查。

改名成 .jsx.bak 是有意的：
面板的 listScripts 只列 .jsx，所以这些文件**不会出现在面板里**，但代码完整保留。

## 文件

| 文件 | 原位置 | 为什么下线 |
|---|---|---|
| ps 连同上方图层合并_穿透检查.jsx.bak | 处理选中图层\ | 功能已并入 ps 连同上方图层合并_自动选层.jsx |
| ps 合并文件夹及其上方剪贴层.jsx.bak | 处理选中图层\ | 被 _自动选层 完全取代（它只能处理无蒙版文件夹） |

## 想恢复某个脚本

把 .bak 去掉，放回 处理选中图层\，然后面板点 ♻ 热重载即可。
